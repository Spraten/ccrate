When you return

Open the program

Tap the Equipment Terminal desktop shortcut. It opens fullscreen. The kiosk’s Desktop button returns to the desktop without closing unrelated applications.

Understand equipment states

Ready is the only state eligible for checkout. Unreviewed equipment needs an explicit inspection. Needs Attention, Maintenance, Quarantined, Archived, Retired, Broken and Trashed remain blocked. Trashed retains its history.

If an operation is interrupted

Open Admin, then Review interrupted operations. Inspect the equipment before choosing an outcome. Do not repeat an uncertain print or create another asset to compensate for an unclear response.
