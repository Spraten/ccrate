Start here

This touchscreen helps you borrow, return, find, and maintain equipment. C-Crate stores the inventory; the companion tracks badges, loans, return notes, and the workshop drawing.

  1. On the Pi desktop, open Equipment Terminal. It opens the kiosk at full screen.
  2. Choose a task on Home. Use your own badge when asked.
  3. Read the review screen, then confirm. Wait for the completion screen before leaving.
The guide works offline. Tap any screenshot to enlarge it. Screenshots use training data; your equipment names and room layout will differ.

Touchscreen navigation

Home opens the task menu. Back returns to the previous step. Storage opens shelves and bins. Edit layout opens the workshop editor. The caution button opens Report problem.

Tap a text field for the on-screen keyboard. Done accepts the text; Close keyboard hides the keyboard while keeping entered text. Scroll the main page to reach lower fields.

If you have edits, leaving may offer Keep editing or Discard & leave. Save first if you want to keep them. An unresolved transaction must be checked through recovery.

Identify yourself

  1. Choose Check Out or Return, then Scan my badge.
  2. Hold your badge QR still in front of the camera. Give it a moment to focus. Allow camera access if Chromium asks.
  3. Check the displayed name before adding equipment. Use Enter badge code if the camera cannot read the badge.

Your badge identifies a native C-Crate member. Keep it private and use only your own badge. Sessions end after a completed checkout or return, or after two minutes of inactivity.

Check out equipment

  1. Identify yourself.
  2. Tap Scan equipment, Enter item code, or Find equipment. Scanned equipment goes directly into your list.
  3. Check the item names. Remove anything added by mistake. Add the other equipment you need.
  4. Tap Review checkout. Use Back to items to correct the list.
  5. Tap Confirm checkout once. Wait for Checkout complete, then tap Done.
Only Ready equipment can be checked out. A blocked or already borrowed item needs attention. Checkout keeps its assigned storage shelf; the borrower is tracked separately.

Return equipment

  1. Choose Return and identify yourself. You may return equipment for a colleague.
  2. Scan each item or use Enter item code or Find equipment.
  3. Keep the assigned shelf unless the equipment is going somewhere else. Tap Shelf to choose or scan a different destination.
  4. If its condition changed, tap Condition and select the appropriate state. Report problems honestly; a routine return does not clear a blocked condition.
  5. Add an optional note, then tap Review return. Check all items and changes.
  6. Tap Confirm return once, wait for Return complete, and tap Done.

Add a return note

  1. In the return list, tap Add note beside the item.
  2. Enter a useful comment, such as “Was dirty, but returned clean.”
  3. Tap Save note. Edit note changes it; Cancel leaves the saved note unchanged.
  4. Complete the return. The saved log automatically adds the badge holder’s name and the completion time.
  5. Find the equipment, open its details, and tap Activity history to read its return notes.

Notes are optional, up to 1,000 characters per item. They can be added without changing condition. A return note is separate from a condition issue note. Notes appear in the log only after the return completes, including a return completed through Admin recovery.

Times use Eastern time, with EDT or EST as appropriate for the date. A pending or cancelled return is not a completed note entry.

Find equipment and read its history

Find Item searches equipment or locations. Browse Stock lets you filter the inventory. Open an item to see its details, assigned location, activity, maintenance, and photos or files.

Choose Activity history for checkout, return, and return-note entries. Admin also has a group activity view. History shows the latest entries; it is not an unlimited reporting/export tool.

When scanning is difficult

  1. Tap Manual in the top bar, or the task’s Enter badge code / Enter item code button.
  2. Enter the exact supported code for the badge, equipment, or location. A badge code is different from an equipment code.
  3. Tap Use code. If it is not recognized, check the code and try a correction.
  4. Tap Back to leave manual entry and continue your task.

For camera scanning, keep the label flat, well lit, and still. Move it gradually closer or farther away; avoid glare. The camera runs while scanning and stops afterward. Use manual entry when the webcam cannot focus.

Report a problem

  1. Tap the caution button beside Admin. Identify yourself if asked.
  2. Scan or select the affected equipment.
  3. Describe the issue, choose its condition, and add a photo if useful. Camera/photo screens have a Cancel option.
  4. Review the report, correct it if needed, then confirm.
Reporting a problem is not proof of a repair. Admin must inspect equipment before marking it Ready.

Borrow and return kits

A kit has a container and an expected component list. Scan the kit and every required component. The verification screen shows what is still missing. Use Use verified kit only when the checklist is complete; Cancel kit returns to the task.

Return the complete manifest together. Missing parts or a changed manifest can block the transaction; ask Admin to inspect the kit instead of borrowing its parts through a workaround.

Shelves, bins, and the workshop

Storage opens the native location tree. A typical path is Workshop → Area → Rack → Shelf → Bin, but cabinets and drawers also work. For rack XYZ, shelf 2, and bin B, the display can show XYZ / 2 / B.

Open a location to see the equipment there. Rack front views show shelves and their bins. Workshop is an overhead view; linked drawing objects connect to those storage locations.

Drag to pan and pinch to zoom on the touchscreen. Open the side tabs for Workshop tools and View controls. Fit brings the drawing into view; Turn view rotates the presentation. View controls also include directional navigation.

Admin: what you manage

Open Admin in the top bar. It includes inventory categories, kits, locations, offline products, CSV imports, recovery, system status, accounts, and badges.

Current prototype: Admin is temporarily open. Anyone at the terminal can access these controls. Restrict physical access and arrange protected Admin access before broad deployment.

C-Crate remains the inventory authority. The kiosk uses its normal records; the drawing is a separate presentation layer. Avoid duplicate records when a previous action has an uncertain result.

Admin: people and badges

  1. In Admin, choose Manage users → New user if the person does not already exist. Enter their name and choose Create user. Email is optional; no password or PIN is required. You can change their picture or optional details through Manage profile. In C-Crate, use Collection → Members → Manage users for the same profiles.
  2. Return to Admin and choose Issue badge: [name] for the correct member.
  3. Use Print one badge, inspect the physical label, and give it to that person.
  4. For a lost badge, use the existing badge’s Revoke action before issuing a replacement.

Names may repeat: use the displayed user ID to choose the correct person. Changing a name or picture preserves their badges and checkout history. Normal kiosk use is badge-only. Do not share badges or photograph their QR codes. Revoke access for people who leave; do not reassign an old personal badge to someone else.

Admin: inventory and condition

Add Equipment creates one individually tracked asset. Identify yourself, enter its name, serial number, category, and assigned location, then review and confirm. Product lookup uses the local offline catalog. Add photos when useful.

New equipment defaults to Unreviewed. Check it physically before confirming that it is safe and Ready. Equipment details provide condition review and maintenance controls.

ConditionWhat it means for borrowing
ReadyEligible for checkout, if available.
UnreviewedInspect first; blocked.
Needs Attention / Maintenance / Quarantined / BrokenBlocked until an appropriate Admin review.
Archived / Retired / TrashedNo checkout; records are retained for history.

“Depreciated” was implemented as Retired. A return alone does not make broken equipment Ready. Mark maintenance completed only after the work is actually done.

Admin: categories, products, and kits

Equipment categories manages native equipment types. Offline products stores reusable product defaults for barcode lookup; it does not need an internet product service. Kit manifests selects a container and its expected equipment components.

Choose existing records carefully. Kit definition keeps component locations intact. Test that the physical kit matches its manifest before putting it into service.

Admin: edit the room and link storage

  1. Open Workshop, then Edit layout. Select an object on the map or from its named button.
  2. Drag it or use position controls. Change its name, dimensions, position, or rotation. Add racks, cabinets, workbenches, tables, fences, gates, doors, areas, or a kiosk.
  3. Open Link storage for a drawing object. Choose an existing C-Crate location or create the appropriate location.
  4. Use Storage to add shelves and bins inside the correct parent. Give sibling locations distinct short codes.
  5. Use Save layout to persist the drawing. Check the save result before leaving.

Duplicating a drawing makes a new drawing object and clears its storage link. Removing a drawing does not delete linked inventory or storage. Moving a native location moves its hierarchy; it is different from dragging a symbol on the map.

The present editor supports one rectangular room, feet, and orthogonal objects. Additional rooms are a future extension. Verify approximate dimensions before relying on the drawing. If another browser saved first, reopen the saved layout and reapply your edits.

Admin: import a CSV

  1. Export CSV UTF-8 from the previous system. Prepare existing locations and categories first.
  2. Choose Admin → Import CSV. Select the file and use a stable source-system name, such as Asset Manager.
  3. Map equipment name and any serial, manufacturer, model, description, location, category, source ID, and original condition columns. Name is required; mapping source ID is recommended.
  4. Set defaults for blank locations/categories. Unknown or ambiguous names need an explicit selection during review.
  5. Review each row. Edit fields and choose its location, category, and condition. Inspect physically before selecting Ready. Use Save review & next or Skip item & next.
  6. Use Batch summary. Resolve unsaved drafts and invalid rows. Confirm creation only for the selected, saved, valid items.
  7. In the label queue, preview the created items’ labels and explicitly confirm the selected prints. Inspect the output.

The importer accepts comma, semicolon, or tab separators, quoted text, and UTF-8 BOM files: maximum 700 KB, 500 items, and 40 columns. Each row creates one asset with quantity 1. Existing equipment is not overwritten.

Admin: review, resume, and avoid duplicates

Previous, Next, and Jump to item keep browser drafts while navigating. They do not save a row for creation. Use Save review & next to persist changes. The summary blocks creation while unsaved edits remain.

To continue later, reopen Import CSV and choose Resume. Use Refresh saved progress after recovery. Stop after current item pauses after the in-flight item finishes.

Keep the same source-system name and map original IDs consistently. Existing serials and source identities block duplicates. Without stable IDs or serials, changed rows may not be recognizable as the same equipment.

An uncertain create or print needs Admin recovery. Do not upload a new batch to work around it. Resolve the saved operation, then refresh the batch.

Admin: labels and printing

Use the item’s label controls or an import batch’s label queue. Preview first, then confirm one print or the selected queue. Equipment and location labels refer to stable native C-Crate records. Badge labels identify a person and must be protected.

  1. Check that the SUPVAN is connected, powered, and has the correct stock.
  2. Inspect both QR and text after printing. Keep labels flat and readable.
  3. If the outcome is uncertain, look at the printer output and open Admin recovery. Do not immediately print again.

The queue stops at an error and remembers completed labels. A printer reconnect is not permission to repeat an uncertain print. If text is faint or clipped, have an administrator review the label layout and stock settings.

Admin: interrupted operations

  1. Open Review interrupted operations. Read the affected item, action, and saved state.
  2. Inspect the physical equipment, C-Crate values, and any printer output.
  3. Choose completion only when the intended physical result and stored values are verified. Choose cancellation only when no irreversible change occurred and the recovery controls permit it.
  4. If native values conflict with the saved plan, stop and reconcile them in C-Crate. Do not force a second operation.
  5. Refresh the original task or import batch. Check the result before starting another transaction.
A normal user can use Check saved result or Open recovery after an uncertain transaction. A return note stays with the saved return plan and appears only after completion.

Admin: status, backup, and restart

  1. Open System status & backup. Check C-Crate, companion, printer, detected camera devices, and free storage.
  2. Use Refresh status to recheck a device after reconnecting it. A detected camera does not guarantee a sharp image.
  3. Choose Create recovery backup, read the confirmation, and confirm when a brief kiosk pause is acceptable.
  4. Wait for the kiosk to restart. Refresh status and verify the backup result.

Backups stay privately on the Pi and may contain credentials. A backup on the same device does not protect against loss of the whole Pi. Arrange protected off-device copies with the maintainer.

Restore requires a matched application, runtime, and data backup while services are stopped. Have the maintainer validate it first; never replace one live database with an old copy. Use the Pi’s normal shutdown before removing power. Open Equipment Terminal again from the desktop after a reboot.

Admin: manage from a laptop or desktop

Join the Pi's network and open http://10.249.140.95:17745. Use Connection Info on the Pi desktop if its address has changed. Sign in with your own C-Crate account.

  1. In C-Crate, open Collection → Members and choose the person’s Issue badge. Issue a badge for an existing member, then confirm printing on the Pi label printer. Revoke a lost badge before issuing its replacement. Use Reprint badge for another copy of a current badge, or Manage badges to issue, replace or revoke it.
  2. Use Collection → Invites for a new person to join the shared inventory with their own password. Equipment Terminal also offers Admin → Create C-Crate account.
  3. Workshop Admin can choose Allow management beside a member to enable their badge, print, import, storage and recovery tools. Removing management access leaves their native C-Crate account and kiosk badge intact.
  4. Use the Workshop sidebar for loans, storage, imports, the label queue, recovery and system status. Each item’s Loans & return notes tab shows its borrowing history. Its existing label dialog also offers Print one label on Pi. Save edits before switching tools.
  5. Click Equipment Terminal for its full workflows, or open http://10.249.140.95:17749 directly. Its desktop header includes a C-Crate button.

Both interfaces use the same C-Crate inventory, native members, badge registry, loans, return notes, workshop drawing and printer. Use the native sidebar to switch tools, or the C-Crate button to return from Equipment Terminal.

Direct Ethernet cable access uses 10.77.0.1. The dedicated cable profile supplies DHCP: do not connect it to a shared router LAN while active. For camera work from a laptop, use the existing Workshop Editor SSH tunnel; plain HTTP network access supports manual codes and management. Laptop badge sessions remain separate from the physical kiosk.

If something goes wrong

What you seeWhat to do
Code not recognizedCheck the exact code and type of label. Correct it or use Back.
Camera permission denied / blurry imageChoose Reconnect webcam and follow the permission or connection steps. Your draft stays saved; Manual remains available.
Equipment cannot be borrowedRead its condition or borrower. Admin must inspect a blocked item.
No changes were madeGo Back to items, correct the task, and review again.
Unknown result / needs reviewCheck saved result or open recovery. Do not start a duplicate action.
Unsaved editsKeep editing and save, or deliberately discard.
Layout changed in another browserReopen the saved layout, then reapply your changes.
Could not close kioskStay on the current screen; ask Admin to use the Pi desktop controls. Reopen Equipment Terminal if needed.
C-Crate unavailable / no responseAsk Admin to check System status. Treat an in-flight write as uncertain.
Before restarting during an error, note the task and item name. After restarting, check saved operations and import progress before retrying.
