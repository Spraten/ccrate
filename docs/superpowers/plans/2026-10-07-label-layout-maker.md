# Label Layout Maker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Embed PrintDesignPro item-label editing in both CACI-Create interfaces with shared templates, reviewed SUPVAN output and paper sheets.

**Architecture:** Build one pinned standalone PrintDesignPro ESM host and reuse its renderer/sheet engine in an isolated Chromium subprocess for authoritative PNGs. Thin native/Terminal adapters use the existing companion permissions, SQLite and durable print jobs; existing Pillow location/badge paths stay unchanged.

**Tech Stack:** Existing Nuxt 4/Vue 3/Pinia native host, independently built PrintDesignPro Vue editor, vanilla Terminal, Python stdlib/SQLite/unittest, installed Playwright/Chromium, existing SUPVAN raster adapter.

**Spec:** `docs/superpowers/specs/2026-10-07-label-layout-maker-design.md`

## Global Constraints

- Draft for written review; no editor implementation or deployment is authorized by these documents.
- Homebox is the account and inventory authority; use existing native UUIDs, APIs, components and helpers.
- Initial bindings: native item name, native `assetId` shorthand and unchanged `/item/{native UUID}`; no badge editing or arbitrary QR generation.
- SUPVAN: 40 × 30 mm stock, 8 dots/mm, maximum 384-dot print width and 16-dot feed reserve; editable output 40 × 28 mm, 320 × 224 dots, 203.2 DPI.
- Profile IDs: `supvan` and `letter`; immutable starter IDs are `starter:{profile}:{left|top|compact}`.
- Paper: US Letter 215.9 × 279.4 mm, initial 60 × 40 mm labels, 10 mm page margins and 3 mm gaps; 3 × 6 grid, 18 labels/sheet; adjustable validated geometry, 300 DPI.
- Four-module white QR quiet zone, integer modules, at least four dots/module for SUPVAN; no clipped, overlapped, skewed, missing or extra item QR.
- Nominal font-size floors are 2.25 mm for SUPVAN and 3 mm for paper, converted exactly to the pinned library units; physical readability remains separate acceptance.
- Canonical SUPVAN PNG is mode `L`, threshold 128 without dithering, all pixels 0/255, final QR decoded before freeze; `sha256` hashes canonical PNG bytes, adapter input is their exact decoded `L` bytes. Paper remains RGB.
- Pin a full upstream commit and dependencies; preserve MIT/font notices; no Homebox toolchain upgrade, paid services, Google Fonts or runtime network fallback.
- Reuse the full existing editor/renderer and sheet code; no replacement DOM editor, Pillow port or arbitrary client-raster printing.
- The pinned same-origin editor is trusted application code; iframe/postMessage checks isolate styles and stale instances, not cookies/parent/local HTTP. Scoped CSP denies external runtime requests while permitting local assets/fonts and validated data images.
- Label preview/paper reads: client 60 seconds, shared-lock wait ≤2 seconds, whole-request render budget ≤20 seconds, ≤36 items/≤2 Letter pages. Durable writes retain 25 seconds and their existing recovery behavior. Read failures carry no physical-uncertainty warning.
- Untrusted document input ≤1 MiB; trusted reviewed-PNG sheet stdin ≤32 MiB; aggregate encoded output ≤16 MiB. Enforce decoded pixel/dimension limits separately, or reject with select-fewer/re-preview guidance.
- Tickets bind profile/label_mm/dpi; paper slots match exactly without scaling/cropping. Changing canvas size preserves element positions, requires explicit adjustment/Save/new review.
- Templates are group-scoped and optimistic-revision guarded; reviewed outputs are group/actor-scoped temporary print intent, expire unattached after 24 hours, and remain while attached to unresolved jobs.
- Never automatically repeat an uncertain create, save or print; browser dialog/afterprint is not physical completion.
- Preserve dirty source and `work/review-fixes-isolation`; execution follows the approved fixes in its own isolated preserved source snapshot.
- Coordinating agent and GPT-6.1 Sol High own requirements, planning and risk review; one GPT-6 Luna Medium coding worker at a time, scoped clean forks, fixes through the existing worker, tests and renewed Sol review before advancing. No silent substitution.
- Use fixtures, temporary databases, intercepted browser requests and mocked printers only; no live credentials/data, device probes, service restart, physical printing or deployment during development.
