Homebox network access

On a laptop, phone, or tablet connected to the same network, open http://192.168.1.61:17745 and sign in with your Homebox email and password. No SSH tunnel or launcher is needed.

For the direct laptop cable, open http://10.77.0.1:17745. On the Pi itself, use http://127.0.0.1:17745.

After changing Wi-Fi, open Connection Info on the Pi desktop to find its current address. Guest Wi-Fi can block access between devices. Internet is not required for Homebox.

The companion and workshop editor still use the existing Workshop Editor tunnel. Codex phone pairing does not expose these browser services. Use Equipment Terminal for checkout, returns, badges, and return-note logs.

Homebox listens on the Pi network interfaces and retains its normal login. Access from outside this network requires a separately configured remote access method.
